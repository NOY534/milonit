# מילונית: הוראות התקנה

מילונית היא אפליקציית רשת (PWA). מעלים אותה פעם אחת לאתר חינמי, ומשם כל אחד יכול להתקין אותה בטלפון בלחיצה, באנדרואיד ובאייפון.

## מה יש בתיקייה

| קובץ | מה הוא עושה |
|---|---|
| `index.html` | המסך של האפליקציה |
| `app.js` | הלוגיקה: חיפוש, תרגום, הגייה |
| `dict.js` | המילון המובנה (245 מילים עם משפטים לדוגמה), עובד בלי אינטרנט |
| `dict-extra.js` | ניקוד למילים של המילון המובנה |
| `dict-auto.js` | מילון מורחב: 2,777 מילים נפוצות נוספות שנוצרו אוטומטית, עם ניקוד ופירושים נוספים. עובד בלי אינטרנט |
| `sw.js` | שומר את האפליקציה בטלפון כדי שתיפתח גם בלי אינטרנט |
| `manifest.webmanifest` | השם, הצבע והאייקון של האפליקציה בטלפון |
| `icons/` | אייקונים |

## שלב 1: העלאה לאתר חינמי (GitHub Pages)

1. נכנסים ל-https://github.com ופותחים חשבון חינמי (אם אין).
2. לוחצים על **+** למעלה, ואז **New repository**.
   - Repository name: `milonit`
   - מסמנים **Public**
   - לוחצים **Create repository**
3. בעמוד שנפתח לוחצים על הקישור **uploading an existing file**.
4. גוררים לחלון את **כל הקבצים והתיקייה `icons`** מתוך התיקייה `milonit-app`. צריך לגרור את התוכן שלה, לא את התיקייה עצמה.
   הקובץ `index.html` צריך להיות ברמה העליונה של המאגר.
5. לוחצים **Commit changes**.
6. עוברים ל-**Settings**, ואז **Pages**. תחת **Branch** בוחרים `main` ו-`/ (root)` ולוחצים **Save**.
7. אחרי דקה-שתיים מופיעה כתובת כמו:
   `https://USERNAME.github.io/milonit/`
   זו הכתובת של האפליקציה.

## שלב 2: התקנה בטלפון

**אנדרואיד (Chrome):**
פותחים את הכתובת. מופיע באנר «התקנה». אם לא מופיע: תפריט ⋮, ואז **התקנת אפליקציה** או **הוספה למסך הבית**.

**אייפון (Safari בלבד):**
פותחים את הכתובת ב-Safari. לוחצים על כפתור השיתוף ↑, ואז **הוספה למסך הבית**.

מעכשיו מילונית מופיעה במסך הבית עם אייקון ונפתחת במסך מלא, כמו אפליקציה רגילה.

## לפני מבחן

1. פותחים את האפליקציה פעם אחת כשיש אינטרנט, כדי שהגרסה העדכנית תישמר בטלפון.
2. לוחצים על **בדיקת מוכנות**. כל השורות צריכות להיות ירוקות. אם חסר קול לעברית או לרוסית, מתקינים אותו בהגדרות הטלפון.
3. לוחצים על **מצב מבחן**. במצב הזה האפליקציה לא פונה לאינטרנט בכלל, ומוצג פס «מצב מבחן פעיל».

החיפוש מזהה צורות של מילים: תחיליות (הספרים, מהבית), רבים (שולחנות, בתים), כתיב מלא וחסר (אישה/אשה), נטיות ברוסית ובאנגלית (книги, кошками, dogs, walked), ופעלים בכל הזמנים, שמובילים לשם הפועל: הלכתי / אלך / הולכת → ללכת, מדברים → לדבר, הזמנתי → להזמין, говорю → говорить, пишу → писать, went → go.

## איך האפליקציה עובדת

ברירת המחדל היא המילון המובנה: מילה שנמצאת בו מוצגת מיד, גם כשיש אינטרנט. רק מילה שלא נמצאת במילון המובנה מתורגמת דרך האינטרנט.

- **בלי אינטרנט:** 3,022 מילים זמינות תמיד. 245 מהן נכתבו ידנית. 2,777 נוספות נוצרו אוטומטית, עם תרגום, ניקוד, הגייה ופירושים נוספים.
- **עם אינטרנט:** כל מילה אחרת מתורגמת דרך שירות התרגום החינמי של Google, עם ניקוד ומשפט לדוגמה. אם השירות לא זמין, יש שירות גיבוי (MyMemory) שמחזיר תרגום בלבד.
- **הגייה:** משתמשת בקולות של הטלפון, ואלה עובדים גם בלי אינטרנט. אם אין בטלפון קול עברי או רוסי, אפשר להוסיף אותו:
  - אנדרואיד: הגדרות, ואז נגישות, ואז המרת טקסט לדיבור. מורידים את השפה במנוע של Google.
  - אייפון: הגדרות, ואז נגישות, ואז תוכן מוקרא, ואז קולות.
  כשיש אינטרנט ואין קול בטלפון, ההגייה מגיעה מהאינטרנט.

## חשוב לדעת

- שירות התרגום של Google שבו האפליקציה משתמשת הוא חינמי ולא רשמי. הוא עובד היום, אבל Google יכולה לשנות או לחסום אותו בלי הודעה. במקרה כזה האפליקציה עוברת לשירות הגיבוי.
- המשפטים לדוגמה למילים שלא נמצאות במילון המובנה מגיעים ממילון אנגלי ומתורגמים אוטומטית. לפעמים הם לא מושלמים.

## הוספת מילים למילון המובנה

פותחים את `dict.js` ומוסיפים שורה בפורמט:

```
עברית|הגייה ברוסית|English|Русский|משפט בעברית|Example in English|Пример по-русски
```

אחרי כל עדכון של קבצים באתר, מעלים את מספר הגרסה בשורה הראשונה של `sw.js` (למשל מ-`milonit-v1` ל-`milonit-v2`). כך הטלפונים יקבלו את הגרסה החדשה.
